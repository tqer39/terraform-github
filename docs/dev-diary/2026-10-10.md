## 実装の詳細

- archived の vulnerability alerts 作成を除外し、既存リソースを moved で移行。
- Terraform タスクに有効な既定 root と明示的な root 選択を追加。
- PR と push の差分で実行対象を選び、手動実行は1件または明示的な all を指定。
- 共通 module / Terraform Action の変更は全 root の plan のみとし、適用は手動で明示。
- plan を保存して同じ実行の apply に渡す。手動実行は plan のみを既定にする。
- mise bootstrap でツール、固定依存、Git フックをセットアップ。
- betterleaks と pnpm を mise 管理に統一。ステージ済み内容と全ファイル検査を区別。
- 秘密検出と対象選択、archived の回帰テストを包括 lint と CI に組み込む。
- 5種類の間接依存を更新。親が固定する smol-toml と KaTeX は限定的に上書きする。
- pnpm の複数文書形式の生成 lockfile を yamllint の対象外にする。
